# Security

Clipback reads selected text and takes screenshots on your Mac, so security problems matter more than usual. If you find one, please report it privately with **Report a vulnerability** on this repo's Security tab rather than in a public issue.

Useful things to include: what an attacker could do, the steps to reproduce it, and your macOS version. You'll get a reply within a week.

Things that count, for example:
- Clipback capturing from a password field or a password manager it should skip
- clips or screenshots ending up anywhere outside your clips folder
- Clipback's windows showing up in a screen share
- any network request at all
